# FSharpLearning

A console application for learning and practicing F# programming language.

## Overview

This project contains a simple F# console application that demonstrates various F# concepts including:

- Basic syntax and string formatting
- Variables and type inference
- Functions
- Lists and list operations
- Pattern matching
- Records
- Options
- Discriminated unions
- Piping and composition
- Sequences (lazy evaluation)

## Prerequisites

- [.NET SDK 9.0](https://dotnet.microsoft.com/download) or later

## Building the Application

To build the application, run:

```bash
cd FSharpLearning
dotnet build
```

## Running the Application

To run the application, execute:

```bash
cd FSharpLearning
dotnet run
```

## Project Structure

```
FSharpLearning/
├── FSharpLearning.fsproj  # Project file
└── Program.fs              # Main application file with F# examples
```
